# Idea name Monorail Tripteron

## Problem
3D Printers are limited in printing long parts such as car pieces. 

## Proposed solution
Create a monorail tripteron system that spans a long y axis.

## Decision notes
N/A

## Objective
- Print parts longer than a desktop printer
- Accuracy on the y-axis
- Affordable
- Easy to calibrate/set up
- Device should be able to fit on a workbench

## Constraints
- Device must use a linear rail
- Device must run on wall power
- Device must not deflect over 1mm
- Device must have an e-stop

## Criteria
- Volume/dimensions
- Accuracy
- Print speed
- Calibration time
- Cost
